# Logo Creator Features Roadmap

## Phase 1 — Basic Logo Builder (First MVP)

This is the minimum feature set required to create simple logos using text and basic shapes.

### Core Features

* Create empty canvas
* Resize canvas
* Zoom in / Zoom out
* Move canvas
* Save project
* Export to PNG / JPG / SVG
* Undo / Redo
* History panel
* Reset canvas

### Basic Design Elements

* Add text
* Font selection
* Font size adjustment
* Font weight adjustment
* Letter spacing adjustment
* Line height adjustment
* Bold / Italic / Underline
* Text alignment
* Text color selection
* Text shadow
* Add shapes
* Rectangle shape
* Circle shape
* Triangle shape
* Polygon shape
* Star shape
* Line shape
* Arrow shape
* Change fill color
* Change border color
* Change border width
* Opacity adjustment
* Rotate elements
* Resize elements
* Move elements
* Duplicate elements
* Delete elements
* Keyboard shortcuts
