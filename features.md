# Webster Features Roadmap

## Phase 1 — Basic Editor (First MVP)

This is the minimum set of features that already allows users to edit images.

### Core Features

* Upload image
* Drag-and-drop image upload
* Create empty canvas
* Resize canvas
* Zoom in / Zoom out
* Move canvas
* Save project
* Export to PNG / JPG
* Undo / Redo
* History panel
* Reset image

### Drawing and Basic Tools

* Brush tool
* Eraser tool
* Color picker
* Brush size adjustment
* Brush opacity adjustment
* Eyedropper tool
* Line tool
* Rectangle tool
* Circle tool
* Arrow tool
* Fill tool
* Text tool
* Font selection
* Text size adjustment
* Bold / Italic / Underline
* Move object
* Delete object
* Keyboard shortcuts

---

## Phase 2 — Basic Image Editing

Once the canvas and tools are working, basic image editing features can be added.

### Editing Features

* Crop image
* Rotate image
* Flip horizontally / vertically
* Resize image
* Brightness adjustment
* Contrast adjustment
* Saturation adjustment
* Hue adjustment
* Opacity adjustment
* Grayscale filter
* Blur effect
* Sharpen effect
* Shadow effect
* Border effect
* Vignette effect
* Noise effect
* Temperature adjustment
* Exposure adjustment
* Highlights / Shadows adjustment

### Selection Tools

* Area selection
* Rectangular selection
* Freehand selection
* Magic wand selection
* Apply effects to selected area only
* Copy / Paste selected area

---

## Phase 3 — Layer System

After the basic editor is complete, implement a professional layer system.

### Layer Features

* Create layer
* Delete layer
* Duplicate layer
* Show / Hide layer
* Lock layer
* Reorder layers
* Change layer opacity
* Rename layer
* Group layers
* Merge layers
* Rasterize text
* Layer masks
* Clipping masks
* Blend modes
* Background layer
* Layer history support

# Recommended Development Order

1. Canvas + image upload
2. Brush, eraser, shapes, text tools
3. Undo / Redo + history
4. Crop / Resize / Rotate
5. Basic filters
6. Selection tools
7. Layers
8. Layer masks + blend modes
9. Advanced filters
10. Templates / Collage / Stickers
11. Project saving
12. Cloud storage
13. AI features
14. Collaboration features
15. Mobile version + final polishing
